# Security policy

Rel2KG is a **local lab**. Default Compose credentials (`rel2kg` / `rel2kg`) are public, weak, and intended only for a database bound to `localhost`. Do not expose the published ports to a network you do not trust. Do not reuse these passwords anywhere else.

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| older commits | No |

## Reporting a vulnerability

Please use [GitHub privately reported vulnerabilities](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository.

If the repository has not enabled private reporting yet, contact the owner through the email on their GitHub profile. Do not open a public issue for a real vulnerability.

This project does not currently run a paid bug bounty.
